任务二 · creative 自定义变换（本课未讲第 7 种效果）

主演示 #wySw4 初始效果为 cube，配置为「无缝循环 + 3.2 秒自动翻页且手动后不停止 + 圆点可点击」。 第 7 个按钮参考官方示例 swiper/demo/257-effect-creative.html，做「电影选片墙」： 上一张缩小左移并带角度，下一张右移放大进场。下方滑块实时调参，调完点按钮即可在上方演示图中看到差别。

“课堂上只讲了 6 种 effect，Swiper 其实还有第 7 种 creative（自定义变换），本课未讲解。请打开官方示例 swiper/demo/257-effect-creative.html，配合 AI 读懂 creativeEffect 的 transform 写法，为演示四新增第 7 个按钮 「creative 电影墙」。效果要求：上一张缩小左移并带角度、下一张放大右移进场（参数自定，但要“像电影选片墙”）； 实现后须向 AI 追问并用自己的话写下：prev / next 的 transform 各控制什么？答辩抽问：transform 里的百分号是相对谁的？ 改一个数值让卡片转 20 度试试？”

官方示例 257-effect-creative 的 transform 写法prev 管离场、next 管待命

creativeEffect: {
  prev: { shadow: true, translate: [0, 0, -400] },   // 上一张：向纵深后退 400px 离场
  next: { translate: ['100%', 0, 0] }                 // 下一张：从右侧 100% 自身宽度处待命
}

读法：translate 是 [x, y, z] 三元组，x 写百分比时以 slide 自身宽度为基准，z 是纵深（px）； rotate 是 [rx, ry, rz] 角度（deg）；scale 是缩放倍数；opacity 是 0~1。 官方示例只做了“后退 + 右侧待命”，要变成电影墙，就得让 prev 同时左移、缩小、绕 Z 轴倾斜， next 同时右移、放大，翻页时才有“选片墙”的层次感。

任务二 · creativeEffect 自定义变换参数

creativeEffect 用 prev / next 两组参数分别描述「离场的那一张」和「入场的那一张」， 每组都由 translate、rotate、scale、opacity、shadow 等字段组合而成。

属性 含义 取值范围 其他可选设置
translate 平移位移 x / y 可写百分比（相对 slide 自身宽高）或 px，z 为 px 纵深 数组 [x, y, z]，或单个字符串 '20%'
rotate 绕三轴旋转 单位 deg，常用 -180 ~ 180 数组 [rx, ry, rz]，只转 Z 轴写 [0, 0, -20]
scale 缩放倍数 0 以上，1 表示原尺寸 直接写数字，如 0.86
opacity 透明度 0 ~ 1 直接写数字
shadow 是否投影 true / false 布尔值
origin 变换原点 CSS transform-origin 关键字 如 'center bottom'
translateEl / rotateEl 只对该元素做位移 / 旋转 CSS 选择器 如 '.lwj_slide-caption'

实现逻辑：浏览器按 translate() rotateZ() scale() 的顺序合成 transform 矩阵， 所以“左移 + 缩小 + 转 -20°”在同一张卡片上是同时发生的；翻页时这组值会过渡到 0 值，卡片即归位正前方。

想亲手验证，回到上方任务二演示区拖动滑块、点「应用参数并切到 creative」，即可看到每一组数值对卡片姿态的直接影响。

现场改 delay：把 autoplay.delay 设为 毫秒 当前 3200 毫秒 ≈ 3.2 秒自动翻一页。
答辩第一问：这段代码什么意思？
autoplay: { delay: 3200, disableOnInteraction: false } 表示每 3200 毫秒自动切到下一张； disableOnInteraction: false 表示用户拖动、点击箭头后自动播放不停止，重新计时继续翻页。
答辩第二问：AI 第一次给的哪里不对、你改了什么？
第一轮 AI 只给了 autoplay: true，既没有 3.2 秒也没有 disableOnInteraction: false， 手动拖一次自动播放就停了；改成完整对象并显式写 false 后才符合「手动后继续」的要求。
答辩第三问：新参数的作用？
delay 控制停留时长，disableOnInteraction 控制交互后是否停播， clickable 让圆点可点，keyboard.enabled 接管方向键， parallax 让 caption 随纵深位移。
答辩第四问：把 delay 改成指定值，预期怎么变？
用上方输入框改成任意值：改小（如 1500）翻页更急促，改大（如 8000）停留更久； delay 只影响自动翻页间隔，不改变手动切换的动画速度（那由 speed 控制）。

答辩笔记

prev / next 的 transform 各控制什么？
prev 描述「已经翻过去的那一张」在左侧的形态（左移、缩小、带角度），next 描述「还没进来的下一张」 在右侧的待命形态（右移、放大），翻页时各自向 translate: [0, 0, 0] 归位。
transform 里的百分号是相对谁的？
相对每张 slide 自身的宽度（不是容器、也不是屏幕）。translate 的 x 写 -20%， 即向左移动自身宽度的 20%。
改一个数值让卡片转 20 度试试？
把 creativeEffect 中 prev.rotate 由 [0, 0, -20] 改成 [0, 0, 20]（或在上方滑块把 rotateZ 从 -20 调到 +20），上一张卡片就改为顺时针倾斜 20 度； 翻到下一张时它仍会平滑归位到 0 度。
第一轮提示词漏了什么？
第一轮只写了「循环、自动播放、圆点」，漏掉了 delay: 3200、disableOnInteraction: false、 圆点 clickable、初始 effect: 'cube'；第二轮逐条编号写清数值与布尔值后，AI 给出的配置才可直接运行。
新增的 keyboard 参数怎么用？
keyboard: { enabled: true } 让 Swiper 监听方向键，需先聚焦展区；关闭开关后调用 swiper.keyboard.disable()，键盘即失效。
