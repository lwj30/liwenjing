目录与文件

为避免依赖远程 CDN，Swiper 的样式与脚本已下载到项目的 cdn/swiper/ 目录， 页面只要用相对路径引用即可，双击本地 HTML 也能正常运行。

文件 大小 作用
swiper-bundle.min.css 18 KB 轮播布局、分页器、箭头等基础样式
swiper-bundle.min.js 151 KB UMD 完整包，含 autoplay、pagination、navigation、七种 effect 与 keyboard 模块
<link rel="stylesheet" href="cdn/swiper/swiper-bundle.min.css"> <script src="cdn/swiper/swiper-bundle.min.js"></script> new Swiper('#wySwLocal', { loop: true, pagination: { el: '#wySwLocal .swiper-pagination', clickable: true } });
